# NEKOTSUKI: Easter eggs (สปอยล์)

> ทุกข้อต้องมีที่มา (ความเชื่อจริง / lore ของเมือง / เกมอื่นของเจ้าของ) และต้องมีผลอะไรสักอย่าง แม้แต่นิดเดียว

> แท็ก: **[ภาค 0]** ทำในภาคนี้ · **[ต่อ]** ทำในภาคต่อ
